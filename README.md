# HumSafar 🧭

**Your companion for exploring India.** HumSafar (हमसफ़र, "travel companion") is a travel planner website built to help people plan trips across India.

🔗 **Live site:** https://shlokpunjal.github.io/HumSafar/

---

## About

HumSafar was built during a website development hackathon within a 2–3 hour time limit. The whole project was vibe coded: we described the idea to an AI assistant, refined it into a detailed prompt, and used that prompt to generate and iterate on the site.
